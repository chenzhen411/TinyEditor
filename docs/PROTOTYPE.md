# 第一阶段原型验证

2026-10-29，当前 Mac，macOS 27.2，Apple Silicon arm64，Release 构建。

最终原型自动集成检查 **59/59 通过**，原始结果见 `prototype-results.json`。这批结果是应用内实际 AppKit、WKWebView、系统剪贴板与子进程检查；不把它们冒充为鼠标拖动验收。

- TXT、Markdown、JSON、YAML：实际 NSTextView 输入、撤销到干净状态、重做、保存与重开，四种源码模式行号。
- 稳定文档跨窗口移动，1→1、1→多、多→1、多→多，原文与 UndoManager 身份保留，移后可撤销。
- Markdown 按需创建 WKWebView，默认预览时不创建编辑器；离线 Mermaid 流程图、行内与块级 KaTeX、HTML、表格和代码高亮。
- 强调、链接、列表、引用、代码、表格、图表、公式、HTML 的选区映射回原文；全选保留 CRLF；普通文本精确子串；实际剪贴板仅包含 UTF-8 纯文本及系统的旧版纯文本别名。
- 当前内存修改可进入预览，HTML 脚本与事件属性被移除，远程图片默认不加载。
- 主进程接收实际第二进程的请求，第二进程收到确认后退出。
- 1/10/30 MB 多行和 10 MB 单行打开、显示、编辑与撤销。

原型暴露并修复了编辑器释放时的 unowned 访问崩溃、分段编辑重复撤销登记、Mermaid 源片段提取、非现存子路径下符号链接边界及沙箱内的系统构建服务限制。

10 MB 单行的首版完整 TextKit 排版为首次显示约 6.8 s、编辑约 2.0 s；改用原生分段投影视图后约 203 ms 和 113 ms，撤销与完整原文一致。

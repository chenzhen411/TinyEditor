# TinyEditor 1.0.3 侧边栏与标签栏布局

标签栏从整窗根视图移入右侧文档区域，与正文、状态栏共用横向边界。左侧最近文件栏从统一工具栏下方延伸到底部，打开和调宽时不再占用标签栏的位置。收起时视图宽度归零，保留再次展开的首选宽度；隐藏状态不绘制原生分隔线。

## 本轮验证

- 83 项隔离 AppKit/WebKit 集成检查通过并正常退出；新增检查覆盖展开对齐、300 pt 调宽后对齐、侧边栏偏移下的拖拽插入索引、第二标签 hitTest、收起后整窗宽度、隐藏侧边栏零宽度和透明分隔线。
- 真实 CUA 鼠标展开 220 pt 侧边栏，原生截图复核标签栏位于正文正上方，最近文件列表从工具栏下方开始。
- 展开时新建第二标签，分别用窗口截图坐标 (672,108)、(1132,108) 切换首个和第二个标签，再用 (928,108) 关闭第二标签，文档身份正确。坐标为该次 825 pt 窗口的 2× 截图像素，不适用于其他窗口尺寸。
- 复核收起后的整窗布局与分隔线绘制。布局状态快照在 evidence/1.0.3-sidebar-open.json 和 1.0.3-sidebar-closed.json；最终安装版的绘制复核记录在 evidence/1.0.3-installed-gui.json，收起无残留竖线，再次展开保留 220 pt 宽度。原生截图在本次会话中复核。

拖放继续使用 NSView 坐标转换，因此标签栏层级改变后不需要手动添加侧边栏偏移。本轮检查了转换与插入位置，没有重新授予系统输入驱动权限，也没有把 1.0.2 的真实跨窗拖拽记录冒充为 1.0.3 的全矩阵重跑。

本轮未改动原文、编码、保存、撤销、预览解析或最近记录的存储逻辑。数据核心既有 3,061 条断言仍适用；当前实际集成、性能及打包结果以 integration-results.json、distribution-results.json 为准。
